# 流星创作画布试用版

本分支基于 leezeqi/canvas 固定版本改造，保留无限画布标识、贡献者信息和完整 AGPL-3.0 许可证。原始贡献者包括 basketikun、HuFakai、tigerowo 和 leezeqi。网络用户可从 `/studio/source` 获取与当前部署提交相符的完整对应源码和安装说明。

## 服务边界

本镜像仅运行 Next.js，不启动原项目的 Go 服务、独立数据库、注册、渠道代理、算力点及匿名上传。只开放 `/studio/canvas`、单项目页面、编译静态文件、开源说明及无敏感信息的健康检查。身份、所有者权限、模型目录、图片生成、项目保存均使用流星 API 的现有接口。

本仓库不包含生产 API Key、环境文件、用户数据或数据库备份。浏览器只能访问已登录本人被授权的数据。图片节点使用手动提交；付费生成结果不明确时停止并提示核对记录，不自动重发。

## 构建与安装

1. GitHub Actions 的 `Meteor canvas pilot` 工作流在 `meteor/**` 分支执行精确依赖安装、TypeScript 检查、路由边界测试和 linux/amd64 镜像构建，推送 `ghcr.io/meteor21c/canvas:pilot-<commit7>`。
2. 根据构建输出固定镜像摘要，设置 `CANVAS_IMAGE` 后使用 `deploy/pilot.compose.yml` 创建独立服务。生产服务器不执行构建。
3. Nginx 仅将 `/studio/` 原样转发至 `127.0.0.1:3010`，保留前缀；`/api/v1/*`、`/v1/*` 和已有图片/视频地址继续进入现有 Sub2API。
4. 服务只绑定回环地址；默认内存上限 512 MiB、Node 堆 256 MiB、CPU 0.5，不挂载用户凭据或数据库。可按实测修改配额。容器可使用只读根文件系统，临时目录为有大小限制的 tmpfs。
5. 访问 `/studio/pilot-health` 检查进程状态；业务验收还需站主访问、项目保存、图片结果和权限验证。该健康接口不代表上游模型可用。

## 保留与范围

画布元数据与媒体文件保留周期不同。试用版沿用站点现有临时媒体清理，不承诺无限期保存生成文件；导出仅包含用户明确导出的安全画布数据。旧生图与视频入口保持可用，盈合视频、长期作品库及其他节点功能待后续验收。
