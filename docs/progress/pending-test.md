# 待测试

- OpenAI 渠道新增「图生图格式」选项，本地渠道和后台渠道均可选择「公网图片 URL（JSON）」，按渠道配置生效，不绑定模型名。选择后通过 `/v1/images/edits` 发送 `images: [{ image_url }]`；已有公网图片直链直接复用，本地参考图上传到已配置且可公开读取的对象存储，无法取得公网地址时停止提交并提示。对要求 SSE 的上游需开启现有图片流式设置。请求、存储和流式解析已通过模拟接口测试，实际渠道生成及页面交互仍待人工确认。
- 新增“Canvas OpenAPI（视频）”渠道协议，默认接口地址留空，由管理员或用户自行填写 Base URL；模型使用平台开放模型 UUID。登录用户的模型列表改由后端安全代理拉取，避免浏览器 CORS 拦截；未登录时仍可手动填写 UUID。验证模型拉取、JSON 公网参考素材、FormData 本地图片/视频/音频与首尾帧上传、`task_id` 轮询、`result_url` 成品解析、失败与 `upstream_error` 展示，以及 UUID 仅出现在视频模型选择器中。
- 修复部署构建阻塞：补齐线上已有的通用参数解析函数和测试辅助函数，即梦签名复用包内已有的 SHA-256/HMAC 函数，视频创作页移除对已删除 AutoDL/KIE 模块和专用面板的引用；固定 Docker 启动脚本为 LF 换行。验证容器启动、视频页侧栏/底部布局、提示词提交及普通参考素材上传，并回归即梦签名。
- 「Sub2API（Grok 视频）」已按中转站文档补齐请求与轮询协议：`seconds`/`duration` 和 `aspect_ratio`/`ratio` 成对发送，参考图使用公网 URL 的 `images` 数组；`grok-imagine-video-1.5` 最多 15 秒和 1 张图，`grok-imagine-video` 最多 7 张图。前后端轮询间隔改为至少 6 秒，连续第 5 次 404 才失败，429 尊重 `Retry-After` 并最多重试 5 次，5xx 最多重试 3 次；标准及旧版视频内容地址均可携带渠道 Key 下载。验证未登录直连、登录后本地渠道代理、云端渠道及原 Grok2API 回归。
- 已移植 Gemini、MiniMax H3/海螺、即梦和火山方舟 Seedance/DoubaoVideo 的渠道协议适配；验证即梦签名、图片响应、视频任务提交与轮询，MiniMax H3/海螺的创建与结果解析，以及不同参考素材和时长/分辨率组合。
- 已移除 APIMart、88API、KIE、AutoDL 四种 AI 渠道协议及相关配置、请求转译和创作台功能；验证后台渠道列表不再显示这些协议，现存协议的文本、图片、视频和语音请求不受影响。
- 全站前端更新为极光玻璃视觉风格：验证桌面悬浮导航、移动端导航、首页、画布节点与工具栏、图片/视频工作台、素材与提示词页面、登录页、404 页面及管理后台在浅色和深色主题下的显示与交互。
- 首页轮播已移除 88API 与 Metaso X 内容及对应跳转链接，验证剩余四项轮播显示和切换正常。
- 用户状态操作区已移除 GitHub 按钮及仓库跳转链接，验证桌面导航和画布侧栏不再显示该入口。
- 桌面侧栏首页入口已改用清晰的首页图标，并仅在首页显示选中态；验证不同页面下的图标辨识度和状态切换正确。
