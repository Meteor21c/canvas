# 待测试

## 侧栏与批量素材上传

- 创作台采用可折叠左侧导航，手机使用抽屉；保留首页演示、五个创作入口、计价标准及返回流星 API，画布编辑保持全屏。
- 首页和图像、视频工作台适应侧栏宽度，底部输入区不覆盖导航。
- 我的素材与素材选择器支持每批最多 20 张图片，单张 20 MiB、并发 2；逐项保存，失败可重试，切换账号停止后续写入。
- 画布支持多选与拖入多个素材，顺序上传并排列；替换现有节点仍为单个文件。
- 参考内容的“＋”提供本地上传、我的素材、从画布选择；选中素材后自动建立参考连接，模型类型限制与生图最多 4 张参考图片保持生效。
- 需验证桌面/手机导航、批量局部失败与重试、账号切换、画布参考预览和刷新后恢复；不以真实付费生成作为界面测试。

## 视频任务状态恢复

- 已提交且不支持取消的视频不再显示停止按钮；取消被拒绝后继续查询原任务，不重发生成请求。
- 服务端任务状态可恢复旧的“停止中”记录，完成结果可正常显示、播放与下载。
- 画布任务取消被拒绝后恢复生成状态，保留结果查询。

## 流星 API v0.8.2 完整适配

- 保留原版创作台页面；增加 `/studio` 子路径及固定内部 API 代理，统一主站站主鉴权，停用独立认证、管理员与外部桥接入口。
- Next 使用真实 Node.js 编译/运行，与 Go 放在同一个非 root 容器；提供只读根、有界内存/CPU、回环端口和持久数据卷配置。
- GitHub 流程新增路由与代理边界测试、模拟主站的镜像启动验收；需验证各页面、Authorization 转发、原版静态资源及数据持久性。
- `/studio/source` 提供作者、许可证和当前提交对应源码；媒体响应拒绝 HTML/SVG 脚本类型并设置沙箱策略。
- 2026-10-28 本地已通过 TypeScript 检查、2 个 Node 路由测试和 7 个 Bun 代理/视频引用测试（37 断言）。独立 Go 边界验收已覆盖站主身份/有效状态、本人密钥过滤与脱敏、凭证和内联媒体项目拒绝、会话到期、固定网关及本地地址 SSRF、执行型/超大图片拦截。
- 独立幂等验收已通过：图像/音频各 32 并发同编号只创建一次；视频 16 并发同编号只向本地模拟主站 POST 一次，响应断开保持未确认；删除/缓存到期后持久回执继续阻止重复提交。测试未请求真实付费生成。GitHub 的完整镜像构建和受限容器运行验收仍需完成。
- 完整 Gin 路由已验证视频签名播放、文件签名和 Range 请求，修复视频内容通过首层签名校验后被二级登录校验拒绝的问题；篡改、过期或跨接口复用签名均被拒绝。Next 代理保留签名 query 且不构造账号身份。联合前端测试现为 2 项 Node、8 项 Bun、45 条断言。

## 流星创作台公开测试

- 正常登录的普通用户可从主站侧边栏“流星创作台”进入；每个账户只使用本人有效密钥与实际分组权限，余额及用量由主站统一结算。
- 创作台顶部与画布账户操作区直接展示“返回流星 API”，手机端保留完整文字入口。
- 图片报价改用普通用户可访问的分组售价接口，不再依赖管理员接口；缺失或未知价格继续保持未知。
- 缺少账户上下文的通用渠道选择拒绝执行，工作流 Agent 显式按当前账户选择渠道，避免跨账户调用。
- 需验证普通用户访问、不同用户渠道和数据隔离、实际账户结算、无密钥时的引导，以及桌面和手机导航。
